Path from concept to code

  • Started as a light reskin (indigo accent) of the existing 5-column kanban + sidebar
  • Pushed drastic (neo-brutalist) — rejected as unprofessional for the audience
  • Pushed drastic again, staying professional — dark "command center" palette, same structure
  • Went structural — dropped the sidebar and kanban columns for a top-nav + grouped-list + master-detail panel
  • Landed here: light default, dark toggle, both themes sharing one indigo accent, real logo mark
